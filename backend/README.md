# Backend

This folder contains the Node.js/Express backend for your website.

- All API logic and integrations (Spotify, Strava, Google Fit, etc.) go here.
- Keep your API keys and secrets in a `.env` file (never commit this file).

To run locally:

```sh
cd backend
npm install
node index.js
```

The backend will run on [http://localhost:3001](http://localhost:3001) by default.
