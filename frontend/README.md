# Frontend

This folder contains the static frontend for your website.

- All HTML pages are in `pages/`.
- Shared styles are in `styles/`.
- Shared scripts are in `scripts/`.
- Images and other assets are in `assets/`.

To view locally, you can use a simple HTTP server:

```sh
cd frontend/pages
python3 -m http.server 8000
```

Then open [http://localhost:8000/index.html](http://localhost:8000/index.html) in your browser.
